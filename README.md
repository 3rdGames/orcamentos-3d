# Orçamentos 3D · 3rd Games

Site estático (HTML + manifest + service worker). Sem build.

## Publicar no GitHub Pages
1. Crie um repositório público no GitHub (ex.: `orcamentos-3d`).
2. Add file > Upload files: envie TODOS os arquivos desta pasta e clique em Commit.
3. Settings > Pages > Source: Deploy from a branch > Branch: main, pasta /(root) > Save.
4. Em 1-2 minutos o site abre em https://SEU-USUARIO.github.io/orcamentos-3d/

## Instalar no iPhone
Abra o link no Safari > Compartilhar > Adicionar à Tela de Início.
